Análisis y Diseño de Soluciones Sustentables Ambientales

Este repositorio alberga el proyecto de investigación desarrollado por dos estudiantes de Ingeniería de Software, enfocado en el análisis, diseño e implementación de soluciones tecnológicas orientadas a la sustentabilidad ambiental.
El objetivo principal de este trabajo es aplicar principios de la ingeniería de software para mitigar problemáticas ecológicas mediante herramientas digitales eficientes y escalables.

📁 Contenido del Repositorio

El proyecto está organizado en las siguientes secciones principales:
• Documentación del Proyecto: Contiene el documento de investigación completa
• Prototipo en Java: Código fuente de la solución interactiva desarrollada
